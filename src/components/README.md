# Components

## Overview
Intermediate presentation layer grouping application layout chrome, page sections, and atomic UI design system primitives.

## Subdirectories & Boundaries
- [Layout](./layout/README.md) — Sticky global navigation header and structured footer with smooth anchor scrolling and accessibility controls.
- [Sections](./sections/README.md) — Full-page presentation sections covering Hero, About, Services, AI Focus, Case Studies, Insights/Blog, and Contact forms.
- [UI](./ui/README.md) — Atomic design system components including forwardRef buttons, cards, badges, animated counters, typewriter text carousels, and interactive canvas graphics.
